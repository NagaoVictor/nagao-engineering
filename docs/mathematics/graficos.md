A inclinacao da reta, depende das caracteristicas do eixo x e y.

Para o processo realizar inversao de inclincao, é necessario que o dominio seja multiplicado por (-1).

Para o aumento de cada ângulo, é necessário o uso de um coeficiente direto na variavel de maior grau, sendo assim, se for uma equação de grau 5, o valor $x^5$ terá que ser multiplicado por uma constante.
